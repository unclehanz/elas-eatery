# Ela's Eatery

A pixel-art karinderya (turo-turo) ordering game. Take the customer's order, fill the plate from the steel pans, then give the right change from the cash box in bills and coins.

Made with Godot 4.7 (GDScript). This repo holds the web build, which runs in the browser.

**Play:** https://unclehanz.github.io/elas-eatery/
